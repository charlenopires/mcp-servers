## 🔄 Fluxo de Trabalho Típico

```bash
# 1. Análise do prompt
python mcp_cli.py analyze "Criar servidor para sistema X"

# 2. Otimização
python mcp_cli.py optimize "Prompt..." --framework CRISPE

# 3. Interface
python mcp_cli.py tailwind button '{"cor": "blue", "tamanho": "lg"}'

# 4. Servidor completo
python mcp_cli.py fastmcp sistema_x '["tool1", "tool2"]'

# OU workflow integrado em um comando
python mcp_cli.py workflow "Sistema X"
```
